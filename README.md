本仓库由 GitHub Actions **自动发布**，仅包含静态看板与站点运行所需的产物。
**请勿在此直接修改，任何改动都会被下次发布覆盖。**

| 文件 | 说明 |
| --- | --- |
| `index.html` | 零后端看板，浏览器 fetch JSON 后渲染 |
| `data/shanghai_housing.json` | 数据集：二手房 + 一手房网签成交 |

## 读数据前先看这三件事

**1. `observed` 与 `reference` 是两种不同的序列，不要混用。**

- `monthly.observed` —— 由逐日明细求和得到，有面积（`area_m2`）、有实测天数（`days_observed`）。
- `monthly.reference` —— 第三方月度锚点，**只有月度总量**，没有日度、没有面积。
  它的对象里根本不存在 `area_m2` 这个键（不是 null，是不存在），
  所以任何拿它算面积的代码都会立刻报错，而不会静默算出错误结果。

**2. 二手房的 `area_quality` 标记面积精度。**

`approximate` 表示上游给的是万位取整的约数（早期月份），`exact` 表示精确到分。
做面积统计前请按需过滤，不要把两者当成同等精度。

**3. 四个来源，其实是一次测量。**

`independence.json` 每次构建自动重算各来源在重叠月份的数值差异。当前结果：
19 组可比月份里 18 组**差 0 套**。差 0 不是「互相印证」，而是「抄的是同一张表」——
两次真正独立的测量之间必然有随机误差。四者最终都指向同一个被反爬保护的
政府网站，本项目无法独立复核。请把它当作**高质量转录数据**使用，
不要当作经过交叉验证的数据。详见 `docs/TRUST.md`。
